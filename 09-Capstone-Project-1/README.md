# Capstone Project 1 – Retail Store Analysis

This project was completed as part of my Power BI certification program.

## Project Overview

This project analyzes student purchasing behavior across different retail store locations and store settings in the United States.

The analysis uses the Student Survey dataset to identify purchasing patterns across different age groups, store locations, and store settings.

## Objectives

The project focuses on:

- Analyzing total purchase amounts by store location and store setting
- Analyzing Outdoor Sports spending across different age groups and store settings
- Comparing purchases across Rural, Urban, and Suburb store settings
- Analyzing purchases by store location
- Comparing Video Games and Outdoor Sports spending across age groups
- Exploring Indoor Sports and Video Games spending across age groups
- Implementing Row-Level Security (RLS)
- Publishing the report to Power BI Service
- Creating a Master Dashboard
- Configuring scheduled data refresh

## Key Visualizations

### 1. Total Purchases by Store Location and Store Setting
A tabular visualization showing total purchase amounts with conditional formatting based on purchase values.

### 2. Outdoor Sports Analysis
A matrix visualization showing Outdoor Sports spending across different age groups and store settings.

### 3. Purchases by Store Setting
A funnel chart showing the total amount of purchases by store setting, including Percentage of First.

### 4. Purchases by Store Location
A pie chart showing the distribution of total purchases across store locations for the Suburb store setting.

### 5. Video Games vs. Outdoor Sports
A scatter plot analyzing Video Games purchases and Outdoor Sports spending across different ages.

### 6. Indoor Sports and Video Games
A SandDance visualization exploring Indoor Sports and Video Games spending across different age groups.

## Row-Level Security

Row-Level Security was implemented using a User Mapping table to restrict data access based on the assigned store setting.

The project includes RLS testing for different users to demonstrate restricted data visibility.

## Power BI Service

The report was published to Power BI Service and a Master Dashboard was created using selected report visuals.

A scheduled refresh was also configured with multiple refresh times throughout the day.
