# Development with Power BI

## Overview

This assignment was completed as part of the **Power BI Certification Training** program.

The assignment focuses on developing a Power BI report using transport-related data and creating different visualizations to analyze trips, revenue, miles, shipping costs, and state-level information.

## Assignment Tasks

The Power BI report includes:

- Connection to the Learn Transport Data Excel workbook
- Card visual displaying Total Miles, Revenue, and Shipping Cost
- Revenue and Total Miles analysis by Origin State
- Map visualization of Revenue by Origin City
- Column chart based on Trip ID
- Funnel chart showing Trip ID by Destination State
- Different colors used to represent destination states

## Tools & Technologies

- Power BI Desktop
- Power Query
- Microsoft Excel

## Files

- `Development_with_Power_BI.pbix` – Power BI report
- `Dashboard.png` – Screenshot of the completed report

## Learning Outcome

This assignment provided practical experience in connecting Excel data to Power BI, creating visualizations, and presenting transport-related data through an interactive report.
