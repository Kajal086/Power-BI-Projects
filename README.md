# Power BI Projects

A collection of Power BI projects completed during my data analytics and Power BI learning journey, covering data extraction, transformation, data modelling, visualisation, Power BI Service, connectivity, and end-to-end capstone projects.

**Topics covered:**

- Importing related tables
- Column charts
- Pie charts
- Map visualisations
- Funnel charts
- Basic report formatting
