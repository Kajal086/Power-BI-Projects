# Assignment 1 – Introduction to Power BI

## Overview

This assignment introduces the fundamentals of Power BI by connecting to the AdventureWorksDW database and creating basic sales visualizations.

## Objectives

The assignment involved:

- Importing the AdventureWorksDW database into Power BI Desktop.
- Importing the FactInternetSales table and related tables.
- Creating sales visualizations using different Power BI chart types.
- Formatting chart titles and applying visual formatting.
- Saving the completed Power BI report.

## Visualizations Created

The report contains the following visualizations:

1. **Sales by Day of the Week** – Column Chart
   - SalesAmount by English name of the week.

2. **Sales by Calendar Quarter** – Pie Chart
   - SalesAmount by CalendarQuarter.
   - Quarter colors were formatted as specified in the assignment.

3. **Sales by Country** – Map
   - SalesTerritoryCountry with SalesAmount.

4. **Sales by Commute Distance** – Funnel Chart
   - CommuteDistance with SalesAmount.

## Data Source

- AdventureWorksDW Database
- FactInternetSales and related tables
