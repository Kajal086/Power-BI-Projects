# Assignment 2 – Data Extraction

## Overview

This assignment focused on extracting data from an Excel file and using Power BI Desktop to transform the data and create visual reports.

## Objectives

The objective was to:

- Import the Adventure Works Sales Excel file into Power BI.
- Prepare and format the required fields.
- Load the Sales table into Power BI.
- Create visualizations to analyze sales performance.

## Data Preparation

The following tasks were performed:

- Reduced and formatted the source Excel file.
- Changed the cell style to Normal.
- Converted the source data into an Excel table.
- Imported the Adventure Works Sales data into Power BI Desktop.
- Converted the following fields to Date type:
  - OrderDate
  - DueDate
  - ShipDate
- Converted the following fields to US Dollar Currency:
  - StandardCost
  - SalesAmount
  - TaxAmt

## Visualizations

The Power BI report contains:

1. **Sales Amount by Sales Territory Group** – Column Chart
2. **Sales Amount by Sales Territory Country** – Map
3. **Top 10 Products by Sales Amount** – Bar Chart
4. **Product Distribution by Category** – Pie Chart

## Tools & Technologies

- Power BI Desktop
- Microsoft Excel
- Power Query

## Files

- `Adventure Works Excel.pbix` – Power BI report containing the completed data extraction and visualizations.
- `Dashboard.png` – Screenshot of the completed Power BI report.

## Learning Outcome

This assignment provided practical experience in importing Excel data into Power BI, preparing data types, applying currency formatting, and creating basic Power BI visualizations for sales analysis.
